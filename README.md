# SpeedArti ANC — démonstration publique

Cette application est une **vitrine interactive**, non une application d'études ANC utilisable en conditions professionnelles.

## Ce que cette démo contient
- exemples de dossier ANC et données **entièrement fictives** ;
- aperçu des étapes : sondages, Porchet, implantation, infiltration et rapport ;
- navigation interactive, simulations préparées et interface mobile ;
- **aucune vraie connexion** à SpeedArti ou Ángel.

## Ce qu'elle ne contient PAS
- moteur de calcul ANC ;
- calculateur Porchet ou d'infiltration ;
- formules, règles métier internes, modèles validés ou tarifs ;
- données réelles de clients ;
- tokens, API, Supabase, code confidentiel ;
- stockage de données utilisateurs.

Aucun résultat de la démonstration ne doit être utilisé pour dimensionner une installation.

**Dépôt de code privé :** `AGENCE-GSTAI-EN-COURS/speedarti-anc-src` (accès restreint).

**Règle :** ÁNGEL PROPOSE — LE PROFESSIONNEL VALIDE.
